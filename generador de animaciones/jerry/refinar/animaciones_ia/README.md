# animaciones_ia/ -- salida del FLUJO IA de Jerry

Una carpeta por animacion: `<nombre>/{<nombre>.animacion.json, <nombre>.py, manifest.json}`, generada con
`ai_export.exportar(..., personaje=JERRY)` (add-on de Alfred, `alfred/refinar/alfred_animation_studio/ai_export.py`).
Es el resultado completo y autonomo; no es el guion del flujo manual (ese vive en `../configuraciones/`).
Reglas y uso: `../../../alfred/refinar/docs/FLUJOS_MANUAL_E_IA.md`.
