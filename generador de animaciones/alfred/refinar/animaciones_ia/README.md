# animaciones_ia/ -- salida del FLUJO IA

Una carpeta por animacion: `<nombre>/{<nombre>.animacion.json, <nombre>.py, manifest.json}`.
Es el resultado completo y autonomo de una animacion hecha por una IA; **no** es el guion del flujo manual
(ese vive en `../configuraciones/`). Reglas y uso: `../docs/FLUJOS_MANUAL_E_IA.md`.
No editar a mano: se rehace y se reexporta con `ai_export.exportar`.
